# 🇫🇷 Français

## Présentation

LibreVerse est un projet indépendant visant à créer
un écosystème de création d'univers numériques.

Son objectif est de permettre à chaque joueur
de posséder un monde unique généré de manière
procédurale selon son profil et ses choix.

LibreVerse n'est pas un simple jeu :
c'est un moteur de création d'univers.


# ⚙️ LVE Genesis Core

LVE Genesis Core est le noyau du
**LibreVerse Engine**.

Il est responsable de :

- la génération procédurale des mondes ;
- la gestion des personnages ;
- les entités et objets ;
- le système de sauvegarde ;
- le moteur hybride 2D/3D ;
- les systèmes physiques futurs.


# 🌍 Génération procédurale

Chaque monde LibreVerse est unique.

La création du monde dépend de :

- la personnalité du joueur ;
- ses réponses au questionnaire initial ;
- une seed unique ;
- les règles du moteur LVE.


Exemple :

```
Profil joueur :
- Explorateur
- Amateur de nature
- Construction

Résultat :
- grandes forêts
- montagnes
- villages isolés
- ressources naturelles
```


# 💻 Langages LibreVerse


## LVS
### LibreVerse Script

Langage officiel de création.

Permet :

- créer des mondes ;
- programmer des objets ;
- créer des missions ;
- contrôler les PNJ.


## LVSThon

Langage simplifié inspiré de Python.

Objectif :

Permettre aux débutants et créateurs
de participer facilement à l'écosystème.


## LVS++RUSST

Technologie interne du moteur.

Fusion conceptuelle :

- puissance du C++ ;
- sécurité du Rust ;
- performance système.
